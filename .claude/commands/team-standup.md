# 團隊 Daily Standup

模擬完整的敏捷團隊 Daily Standup，各角色輪流報告專案狀況。

## 會議流程

依序執行以下角色報告：

### 1. PM 報告
- 檢查專案里程碑進度
- 評估文檔完整性
- 識別風險項目

### 2. 架構師報告
- 檢查技術架構健康度
- 評估重大技術決策
- 識別技術債務

### 3. 開發者報告
- 檢查最近代碼變更
- 評估功能完成度
- 識別開發障礙

### 4. QA 報告
- 檢查測試執行狀況
- 報告發現的 bug
- 評估品質風險

### 5. DevOps 報告
- 檢查建置狀態
- 評估部署準備度
- 識別環境問題

## 執行 Standup

請依序執行：
1. 每個角色簡短報告（3-5 點重點）
2. 識別跨團隊依賴或阻礙
3. 提出今日優先處理事項
4. 生成 Standup 總結：
   - 📊 整體健康度評分（綠/黃/紅）
   - 🎯 今日優先事項（Top 3）
   - ⚠️ 需要關注的風險
   - 🤝 需要協作的事項

開始 Daily Standup！
